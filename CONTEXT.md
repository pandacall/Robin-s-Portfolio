# Robin's Portfolio

The public portfolio of John Robin B. Cubi, a Software & AI Engineer. It exists to turn visitors, mainly hiring managers, into conversations about a role.

## Audience

**Visitor**:
Anyone who lands on the portfolio. The primary Visitor is a **Hiring Manager**. Clients and peers are secondary.
_Avoid_: User, reader, audience

**Hiring Manager**:
The person (or recruiter acting for them) who decides whether Robin gets an interview. Every section is judged by whether it helps them say yes.
_Avoid_: Recruiter (as a separate concept), employer

## Work

**Project**:
A finished piece of work that Robin chose to feature and would be happy to discuss in an interview. It is a curated item, not a mirror of a GitHub repository. Exercises, course repos and experiments are not Projects.
_Avoid_: Repo, app, work sample

**Origin**:
Where a Project came from: **Work** (built as part of a role in Experience) or **Personal** (built on Robin's own time). Every Project has exactly one Origin.
_Avoid_: Type, category, source

**Rebuild**:
A Personal Project that re-implements the architecture of a Work Project from scratch, in a new public repo, under a new name and using only Illustrative Data (fictional entities). It openly says which role in Experience the original came from, but never reveals the original's name, data or results, and never claims to be the production system.
_Avoid_: Clone, fork, demo version, replica

**Private Project**:
A Project whose code cannot be shown. It is presented as a write-up (what it does, how it works, the outcome) with the label "Private — demo on request", and never with a code link. Every Work Project is a Private Project unless Robin has cleared it for public release; a cleared Work Project records that clearance and may link its code and live deployment (Oplan Tindig).
_Avoid_: Hidden project, confidential repo

**Case Study**:
The long-form write-up of a Project: the problem, how Robin solved it and the outcome. It uses redrawn diagrams and published metrics, and never screenshots of real government data or chats. Only some Projects get one.
_Avoid_: Write-up, deep dive, project page

**Project Card**:
The short summary of a Project shown in listings. Every Project has one, and it links to the Case Study when one exists.
_Avoid_: Tile, thumbnail, teaser

**Interactive Demo**:
A hands-on piece inside a Case Study that lets a Visitor operate a simplified version of the system, driven only by Illustrative Data.
_Avoid_: Widget, playground, simulator

**Confidential Detail**:
Anything from Robin's government work that must never appear on the portfolio: internal IDs and URLs, credentials, names of officials or colleagues, real per-provider results, complaint counts, internal-only rules, and real logos. Published metrics and Robin's own methods are not Confidential Details.
_Avoid_: Sensitive info, private data, secrets

**Illustrative Data**:
Made-up numbers and fictional entities (for example an invented telco), always visibly labelled as illustrative. It is never real data, never derived from licensed or internal sources, and never a real provider's result.
_Avoid_: Sample data, mock data, dummy data

## Skills

**Stack**:
The curated, grouped set of Stack Items that Robin claims as working skills.
_Avoid_: Skills list, tech list, toolbox

**Stack Item**:
A single technology in the Stack. Each one is backed by at least one Project that uses it, so the claim can be checked. A technology with no backing Project is not a Stack Item. It may appear only in the plain "Also worked with" line.
_Avoid_: Skill, tool, badge

**Credential**:
A completed course or certification (e.g. Google Cloud ADK). Credentials support Stack Items and are listed beside them, not as a section of their own.
_Avoid_: Certificate, badge, training

## Supporting sections

**Experience**:
Robin's employment history: roles, organizations and dates. An Experience entry links to the Work Projects built in that role, rather than repeating them.
_Avoid_: Work history, career, timeline

**CV**:
The downloadable résumé document offered to Visitors.
_Avoid_: Resume (use CV everywhere)
