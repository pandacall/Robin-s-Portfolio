# Publish the full Six-Pillar method

The Oplan Bantay Signal Case Study publishes Robin's real Six-Pillar grading method: pillar weights, formulas, thresholds and grade bands. Its Interactive Demo runs that real formula on Illustrative Data. We chose this over publishing only the pillar names ("structure only") because a working, real method is far stronger evidence of design skill than a vague description. The method was not public before, so once this ships it can't be taken back. Robin is responsible for confirming clearance with OASIS before launch.

## Consequences

- Only the method is published. Everything it is applied to stays private: real per-provider scores, city results, complaint counts, internal-only grading rules and the monthly reports themselves (see **Confidential Detail** in `CONTEXT.md`).
- If the method changes after publication (a v3.2), the Case Study describes the version current when Robin left (v3.1, May 2026) and says so.
